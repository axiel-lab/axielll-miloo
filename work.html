AsTral GG

Ongoing

A multi-purpose Discord bot, and the biggest thing I’ve built. The goal is for each system to be reliable and easy for server staff to manage, so I keep adding features and refining the ones that already exist.

What it does

  • Ticket handling for support and requests

  • Music playback through Wavelink
  • Community utilities
Built with
Python, discord.py, SQLite, Wavelink

Experiments

Blackjack helper

Experiment

A small Python experiment that reads a hand and suggests a move using basic blackjack strategy. It started as a way to turn a decision I kept making by hand into a quick reference.

Built with
Python, Discord, strategy logic

Try it here

This is a browser version of the idea, not the bot itself. It assumes the usual casino rules: four to eight decks, the dealer stands on soft 17, doubling after a split is allowed, no surrender. Basic strategy is a reference table. It doesn’t beat the house.
